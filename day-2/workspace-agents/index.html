Cómo usar este laboratorio

La secuencia correcta: caso, agente, skills, permisos, tests y despliegue

Un Workspace Agent no debería nacer como un prompt gigante. Debe diseñarse como un flujo operativo con propósito, límites, herramientas, módulos reutilizables y criterios de publicación.

1. Caso

Selecciona un flujo NATEEVO repetible y con salida revisable.

2. Agent spec

Define misión, trigger, fuentes, acciones y output.

3. Skills

Extrae metodología reutilizable: QA, evidencia, red team o briefing.

4. Gobierno

Prueba, limita permisos, exige aprobación y versiona.

Regla de diseño

El agente decide cuándo actuar y coordina herramientas. Las skills definen cómo ejecutar bien una parte especializada del trabajo. Los conectores determinan qué puede leer o modificar. Los tests deciden si se puede publicar.

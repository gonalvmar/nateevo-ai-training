Cómo usar este laboratorio

La secuencia: rol, diagnóstico, laboratorios, integración y validación

El laboratorio convierte el manual del Día 3 en un flujo operativo. La regla de oro es la misma: Copilot acelera la producción; el criterio profesional valida la decisión.

1. Rol y caso

Selecciona tu rol NATEEVO. Los prompts y datasets se adaptan al perfil.

2. Diagnóstico

Decide qué Copilot o agente usar antes de abrir el primer documento.

3. Laboratorios

Word, Excel + Analyst, PowerPoint y Researcher con prompts ya redactados.

4. Pack ejecutivo

Integra todo en un paquete revisable y descarga el material reutilizable.

Regla de oro

La IA produce borradores; tú validas. Distingue siempre [HECHO], [HIPOTESIS], [RECOMENDACION], [PENDIENTE], [NO LOCALIZADO] y [VERIFICAR]. Si dudas sobre si un dato puede compartirse, anonimízalo.

Seguridad y privacidad

Microsoft 365 Copilot opera dentro del límite del servicio Microsoft 365. Los prompts, las respuestas y los datos accedidos vía Microsoft Graph no se usan para entrenar modelos fundacionales. Aun así, cumple las políticas internas de NATEEVO y del cliente: no pegues datos personales, credenciales, contratos ni información de cliente si el entorno no está aprobado para ello.

Laboratorio 1 · Word + Copilot Chat

Memo ejecutivo: de materiales dispersos a documento de 1-2 páginas

Objetivo: crear un memo que pueda usarse como briefing previo, resumen de diagnóstico o base de propuesta. Trabajo por iteraciones: ordenar, redactar, adaptar por audiencia, red team.

Rol activo: —
Tiempo estimado: 30 min · Salida: memo de 2 páginas + 3 versiones por audiencia

Material de entrada

    Configuración recomendada

    Word Copilot
    Abre el documento limpio. Si tienes materiales sueltos, pégalos como texto plano al inicio o adjúntalos al chat de Copilot dentro de Word.
    Copilot Chat (chat.copilot)
    Úsalo cuando los materiales están en distintos archivos. Permite hacer referencia a documentos de Microsoft 365 y a la web pública.

    Errores comunes

    • Generar memo sin ordenar primero el contexto: Copilot completa huecos con texto genérico.

    • Pegar nombres reales de cliente sin necesidad: viola política aunque no haya datos sensibles.

    De tabla a lectura de negocio: análisis accionable, no solo gráficos
    La meta no es generar visualizaciones, sino formular mejores preguntas y proponer acciones razonables. Excel Copilot trabaja sobre la tabla activa; Analyst permite exploraciones más profundas y multifuente.
    
  
    
    
    Rol activo: —

    Datasets recomendados para tu rol
    
        
      
        
      Antes de cargar el dataset
      Asegúrate de que la tabla tiene cabeceras claras, una fila por registro, formato uniforme y campos sin caracteres especiales. Si vas a usar Analyst, conviene exportar a CSV/XLSX limpio: Analyst funciona mejor sobre datos tabulares estructurados que sobre informes con celdas combinadas.
      
      
      
      
      
        
      Cuándo Excel Copilot, cuándo Analyst
      
        
      
          
      Excel Copilot
      Para fórmulas, formato condicional, resúmenes rápidos, sugerencia de gráficos y explicación de fórmulas existentes sobre la tabla activa.
      
          
      Analyst (agente)
      Para análisis exploratorio multifuente, hipótesis, cálculo de métricas, validación de fórmulas y explicación de patrones. Trabaja como analista junior con acceso a varias tablas y al chat.
      
          
      Copilot Chat con archivo adjunto
      Útil cuando la tabla es pequeña y quieres pedir lectura de negocio sin moverte de Word o del chat.

        Narrativa ejecutiva: del memo y el análisis al deck que pide una decisión

        PowerPoint Copilot
        Crea presentación a partir de un documento de Word o de un brief. Mantiene el deck dentro del estilo corporativo. Verifica siempre las cifras propuestas.

        Laboratorio 4 · Researcher
        Contraste externo con fuentes: cuando el caso necesita más que tus archivos
        Usa Researcher para tendencias, benchmarks, riesgos y comparativas. No lo uses para decorar el entregable con referencias irrelevantes. Researcher recopila, analiza y resume información de la web y de documentos de trabajo conectados.
        
  
        
    
        Rol activo: —
        Tiempo estimado: 20 min · Salida: informe con fuentes y nivel de confianza
        

    
        
      
        
        
        Cuándo usar Researcher
        
        
        
          
        NecesidadEjemplo aplicado a tu rol
        
          
        
        
      
        
      
        
        
        Configuración recomendada
        
        
        
          
        Researcher (agente)
        Investigación multietapa con citación de fuentes. Permite acotar el alcance: sectores, geografía, periodo. Devuelve niveles de confianza.
        
          
        Copilot Chat con web
        Para búsquedas puntuales rápidas. Menos riguroso que Researcher para informes con fuentes.
        
          
        Claude / ChatGPT con búsqueda
        Útil para contrastar conclusiones de Researcher o para red team de la propia investigación.
        
        
        
        
        Riesgo principal
        Researcher puede traer ruido si el alcance es demasiado amplio o presentar predicciones como hechos. Siempre revisa fechas, tipo de fuente y nivel de confianza antes de citar.

        Bonus · Outlook · Teams · Cowork
        Resumir hilos, sintetizar reuniones y reutilizar contexto entre proyectos
        Tres usos complementarios que rara vez son el entregable final, pero ahorran tiempo en la fase de preparación y en el follow-up.
        
  
        
    
        
      
        Outlook Copilot
        Resume hilos largos, genera borradores de respuesta y extrae compromisos. Útil para preparar follow-up tras la reunión sin enviarlo directamente.
        
      
        Teams Copilot
        Resumen de reunión con acuerdos, tareas y preguntas abiertas. Verifica siempre los responsables y fechas que extraiga: las inferencias en transcripciones suelen estar mal asignadas.
        
      
        Cowork
        Para organizar la carpeta del proyecto, reutilizar contexto entre archivos y mantener una biblioteca personal de prompts. Funciona como sistema de archivos persistente.
        
    
        
    
        
    
        
    
        

    
        Sobre el follow-up
        Redacta siempre el email de seguimiento como borrador no enviado. La automatización del envío sin revisión es la principal vía por la que un agente inventa un compromiso, un responsable o una fecha que no existe.
